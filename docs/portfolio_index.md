Short notes for recruiters

- Each project contains a README and one or more runnable artifacts (notebook, app, CSV).
- To view notebooks as HTML: install jupyter and run: jupyter nbconvert --to html path/to/notebook.ipynb
- To run Dash apps: pip install -r requirements (or pip install dash pandas plotly) and run the app script.
