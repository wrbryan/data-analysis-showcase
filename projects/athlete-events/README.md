# Athlete Events

Business problem
A general analytics demonstration exploring event-level data to show data-cleaning, aggregation, and visualization skills.

Objective
Showcase data-cleaning steps, example analyses, and one readable output (chart or summary) that a non-technical reviewer can quickly understand.

Tools
Python, Pandas, CSV, Jupyter

Approach
1. Ingest and clean raw event-level CSVs.
2. Standardize key fields and handle missing data.
3. Produce a short set of analyses and one or two visualizations.
4. Add a one-page summary and screenshots for recruiters.

Key outputs
- Notebook or script demonstrating the analysis
- One-page summary and screenshot(s)

Skills demonstrated
- Data cleaning and transformation
- Aggregation and visualization
- Communicating findings to non-technical audiences
